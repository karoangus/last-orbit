# Last Orbit · لست اوربیت ۲

بازی فضایی فارسی و راست‌به‌چپ برای مدیریت اکسیژن، موتور و خدمه؛ بدون وابستگی اجرایی، بدون مرحلهٔ build و قابل نصب به‌صورت PWA.

## نسخهٔ ۲ چه دارد؟

- **مدار کوتاه** (۳٬۰۰۰ کیلومتر) و **سفر کامل** (۹٬۰۰۰ کیلومتر).
- دو نقطهٔ پشتیبانی در یک‌سوم و دوسوم مسیر: انتخاب اکسیژن، انرژی یا تعمیر سیستم‌ها. بسته را می‌توان برای بعد نگه داشت.
- محافظ قابل خاموش‌کردن موتور، نشانگر مسیر، امتیاز و رکورد مستقل برای هر مسیر.
- توقف دستی و توقف خودکار هنگام پنهان‌شدن صفحه یا خروج فوکوس؛ بدون مصرف منابع در پس‌زمینه.
- حالت کم‌تحرک/سبک، پشتیبانی از تنظیم کاهش حرکت سیستم، کنترل کیبورد و چیدمان موبایل/افقی.
- ۶۱ رویداد با بحران‌های چندمرحله‌ای، تخصص و خستگی خدمه.

**ذخیره‌سازی:** فقط تنظیمات و رکوردها در مرورگر ذخیره می‌شوند. سفر جاری بعد از بستن یا reload صفحه قابل ادامه نیست. خرابی یا مسدودبودن storage مانع بازی نمی‌شود.

## اجرای محلی

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

صفحه را از `http://localhost:8080` باز کنید. میزبانی production فقط به `index.html`، `sw.js`، `manifest.webmanifest` و پوشهٔ `icons/` نیاز دارد. نصب و آفلاین‌بودن PWA به HTTPS یا localhost و حداقل یک بار بارگذاری موفق آنلاین نیاز دارد. مسیرهای نسبی با GitHub Pages زیرپوشه‌ای سازگارند.

## کنترل‌ها

| کنترل | عملکرد |
| --- | --- |
| نگه‌داشتن شتاب یا `Space` | شتاب با رعایت cooldown و محافظ موتور |
| `P` یا `Esc` | توقف / ادامه؛ Esc ابتدا کارت خدمه را می‌بندد |
| `1`، `2`، `3` انگلیسی | انتخاب امن، سریع یا ریسکی برای فوری‌ترین بحران |
| کلیک یا لمس خدمه | مهارت‌ها، مأموریت و استراحت |
| بستهٔ پشتیبانی در نوار مسیر | توقف و انتخاب بسته |

## تست و توسعه

Node.js 22 و Python 3:

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

- `npm run test:unit`: شش تست سرویس‌ورکر (پاک‌سازی cache، آفلاین، خطای شبکه/سرور و revalidation).
- Playwright: ۲۳ سناریو در دو پروفایل Chromium دسکتاپ و موبایل، از جمله سفر کامل با seed ثابت، تمامی رویدادها و گزینه‌های مراحل، قفل/مأموریت خدمه، ۳۰/۶۰/۱۲۰ هرتز، توقف، آفلاین و صفحه‌های کوچک.
- `CHROMIUM_PATH=/path/to/chromium npm test` برای مرورگر موجود در محیط؛ در حالت عادی مرورگر نصب‌شدهٔ Playwright استفاده می‌شود.
- برای قلاب‌های تست، `?debug` به URL اضافه کنید (`window.__lo`). این رابط برای بازیکن عادی منتشر نمی‌شود. `step(1/60)` فقط ابزار آزمون است.
- GitHub Actions تست‌ها را روی PR و push به `main` اجرا می‌کند.

### تصمیم‌های مربوط به کارایی

شبیه‌سازی fixed-step با نرخ ۶۰ هرتز و سقف backlog برابر ۲۵۰ میلی‌ثانیه، رندر HUD حدود ۱۰ هرتز و کارت بحران حدود ۴٫۵ هرتز است. هندسهٔ اتاق فقط هنگام تغییر اندازه خوانده می‌شود و حرکت خدمه با transform انجام می‌شود. در توقف، RAF بعد از آخرین callback متوقف می‌شود؛ هیچ موتور گرافیکی، فونت دانلودی یا وابستگی اجرایی جدید اضافه نشده است.

تست‌ها در Chromium انجام شده‌اند؛ پروفایل موبایل شبیه‌سازی است، نه تست روی سخت‌افزار واقعی. Safari/iOS و Firefox هنوز تست دستی جداگانه می‌خواهند. گذراندن این تست‌ها به معنی تضمین نبود تمام باگ‌های ممکن نیست.
